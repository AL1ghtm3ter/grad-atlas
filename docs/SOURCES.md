# 官网检查的含义

网页同步与官网检查是两件事。

Agent 写入本地记录后，网页通过 SSE 接收更新，并在连接恢复时重新读取。官网检查则比较页面文本的 SHA256：首次为 `baseline`，相同为 `unchanged`，不同为 `changed`，无法读取为 `error`。

```sh
npm run agent -- check-sources
```

检查会去掉 HTML 标签、脚本、样式和多余空白，再比较文本。不会执行 JavaScript，也不解析 PDF。因此它不能证明招生要求仍有效，也不能判断某一变化就是截止日调整。动态页面、验证页面、PDF 和需要登录的内容交给 Agent 另行核对。

变化后先保留提醒。Agent 实际阅读官方内容并核对周期后，更新具体事实与 `verifiedAt`，再把已核对观察的哈希写入来源的 `reviewedHash`。后续重复检查相同文本不会自动清除尚未处理的变化。

用户要求定时检查时，Agent 设置 `settings.refreshMinutes`，允许 15–1440 分钟，0 表示关闭。启动服务后从启动时间开始计时；服务停止或电脑休眠期间不会检查，也没有云端补跑。网页只列出处和更新记录，不向模型自动发送资料。

请求只访问来源指定的公共 HTTP/HTTPS 网页，限制标准端口、响应大小、超时和重定向；每个重定向都重新核对 DNS，拒绝本机与内网地址。网页内容可能包含无关文本变化，人工核对不可省略。

实际官网可能拒绝自动请求或超时。本地检查失败时保留 `error`，由 Agent 通过可访问的官方网页另行研究；不能为清除错误而假设要求未变，也不能把验证页当作招生正文。1.1.0 在 2026-10-28 的请求失败及当时的人工核验范围见 [真实来源验收](qa/real-applications-20261028.md)；1.2.0 的修复与复测见文末报告。

## 公开阅读回退（1.2.0）

默认只直连。遇到网络连接失败、HTTP 403或安全验证页，可以让 Agent 设置 `settings.sourceReader` 为 `"jina"`，启用 [Jina Reader](https://jina.ai/reader/) 回退。设为 `"off"` 关闭。配置与其他个人设置一起保存在本地，仍由 Agent 按当前版本校验写入。

优先级为工作区设置、进程环境变量 `GRAD_ATLAS_SOURCE_READER`、默认关闭。环境变量主要用于隔离测试或尚未保存该设置的旧工作区；已有显式 `off` 时不会被它开启。定时检查和 CLI 使用同一套策略，回退本身不会开启定时检查。

直连按 `HTTP_PROXY`、`HTTPS_PROXY`、`NO_PROXY` 及相应小写变量选择现有网络路径，不读写系统代理。直连保留已检查的全部 IPv6/IPv4 地址；使用代理时，也把连接目标固定到已检查的公网IP，并保留原域名的Host和TLS验证。[Node代理支持](https://nodejs.org/api/https.html#new-agentoptions)从22.21/24.5开始提供；[地址回退机制](https://nodejs.org/api/net.html#socketconnectoptions-connectlistener)支持同一次连接尝试多个地址。

部分代理会把域名解析为 `198.18.0.0/15` 或 `2001:2::/48` 的Fake-IP。只有已配置代理、域名的全部答案均属于这类代理保留地址时，程序才向固定公网地址 `1.1.1.1` 发起[HTTPS DNS查询](https://developers.cloudflare.com/1.1.1.1/encryption/dns-over-https/make-api-requests/dns-json/)，失败时尝试同一服务的备用地址 `1.0.0.1`。查询只含域名，不含页面路径或个人信息；真实答案仍须全部为公网地址，并固定连接。普通私网地址、混合私网答案、内部域名和字面保留IP继续被拒绝。DNS正结果按TTL最多保留60秒，这与正文的无缓存请求分别处理。

回退只对不带查询参数的公开内容页生效，不发送个人档案、Cookie、登录信息或代理凭据给阅读服务。登录入口和需要账号的页面继续交给 Agent 单独核对。Jina 是第三方阅读通道，来源页会明确标出；它读到的内容不能称为官网直连成功。

每次回退请求使用 `X-No-Cache: true`、`X-Cache-Tolerance: 0` 和 `DNT: 1`，要求重新抓取。收到响应后，程序要求原始来源URL与请求一致、接口和上游状态均为200、正文完整，并拒绝接口报告的旧缓存和安全验证页。仅HTTP成功或标题相似都不足以建立基线。实际招生规则仍需 Agent 阅读确认。

连接阶段停滞时，在总时限内换用下一个已核对的公网地址。阅读服务遇到临时网络超时或5xx等临时服务错误，只重试一次，并重新请求无缓存正文；不会用旧哈希或旧正文当作本次成功。来源不符、缓存警告、私网地址和不完整正文等校验失败不重试；持续失败仍保存错误。429限流也不会立即反复请求。

观察记录新增 `method`（`direct` / `jina`）、`sourceUrl`、`upstreamStatus` 和 `cacheMode`。旧记录未写 `method` 时按直连兼容。直连HTML与阅读版Markdown可能格式不同，因此换通道时重新建立基线，不直接报告要求变化；同一通道的后续正文再按哈希比较。失败继续保留原哈希与错误，事实核验日不自动改变。

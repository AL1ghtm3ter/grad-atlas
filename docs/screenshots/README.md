# 实际示例截图

这些图片来自运行中的 GradAtlas 示例实例，没有绘制或拼接界面。截图前由 `examples/demo.mjs` 生成独立虚构工作区；未读取私人 `.local/`、原申请页或浏览器个人档案。

截图日期：2026-10-27。桌面视口 1440 × 1000，手机视口 390 × 844；PNG 使用完整页面截图，因此文件高度可能大于视口高度。浏览器为现有 Edge 的无头实例。

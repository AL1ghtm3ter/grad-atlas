## 使用这些结论时

真实院校与公开招生规则来自官网；个人成绩、材料准备、联系、递交、推荐信、面试、录取、资助和入学事件是隔离环境中的模拟，没有代替用户发信、注册、支付或提交真实申请。公开研究基线及逐条来源见 [研究记录](../research/README.md)。

首次安装的完整实机环境为 Windows、Node.js 24.18.1 和 Edge，另有 Ubuntu GitHub CI。macOS/Linux 桌面、外部真人长期使用和所有 Agent 客户端尚未完成同等验收。源站拒绝请求时的阅读回退也不保证未来始终可用。

原始对话、模拟个人快照、安装日志和测试截图保存在被忽略的本地证据目录，不随报告包上传。公开报告保留复现步骤、来源和边界；源码包内 `tests/` 可用 `npm test` 重跑，构建命令为 `npm run build`。

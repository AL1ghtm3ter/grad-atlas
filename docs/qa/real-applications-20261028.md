## 执行方式

- 使用实际 Edge、Playwright、`createApp({ dir: 隔离目录 })`、Store 和隔离 CLI 副本；服务使用系统分配的临时本机端口，没有改动既有实例或正式数据。
- CLI 为异步子进程。更新先快照、干跑校验，再按当前版本写入；等待网页显示对应版本后检查内容。未把同进程同步命令阻塞服务造成的占用算作产品问题。
- 递交、联系回复、推荐信、面试、录取、接受、婉拒、撤回和入学均写入原生 `application`。编号以 `LOCAL-SIM-` 开头；记录和界面均标明本地模拟。通用扩展只保存额外阅读笔记。
- 每校保存官方事实冻结摘要；每次个人操作前后检查院校、岗位、事实、来源和官方里程碑未变。最终两遍的工作区事实摘要相同，且流程结束后保持原值。

分别执行了产品函数的实际请求和隔离 CLI 的真实 `check-sources`，均只选四校代表主 URL，没有逐一自动抓取全部 36 条来源。两次最终全周期的请求结果与独立 CLI 一致：

# GradAtlas 第二轮博士申请全周期验收

测试日期：2026-10-27。场景保持不变：虚构申请者正在英国 Queen Mary University of London（QMUL）就读理论物理硕士，希望申请欧洲及美国博士。

**第二轮最终结果：通过本场景验收。** 修复后使用异步 CLI，在两个全新隔离目录中各完成一次全周期，每次 78 项检查全部通过；另外 6 项平台检查、4 项日期检查和 5 项界面检查通过。重复运行不重复计作新增功能覆盖，因此共 93 项不同检查通过。当前没有本轮已确认、尚未修复的阻断缺陷。

第一轮 5 个缺陷与 2 组缺失均完成复测。第二轮新增发现的 3 个跨页面一致性缺陷已修复，并在两个完整周期中再次验证。全周期由原生 `application` 结构承载，通用扩展仅用于额外阅读记录。

## 模拟边界与执行方式

- 题设已确认的信息只有：QMUL 理论物理硕士在读、博士目标、欧洲和美国地区。成绩、计分体系、语言、预算、国籍、研究成果、具体研究问题和个人入学周期未被编造；未知字段持续留空或明确待确认。
- 三个虚构目标分别采用岗位招聘、导师制、项目制，未从“欧洲”自动推断招生方式。目标、导师、日期、金额、回复、递交编号、offer 和入学事件均标注为 QA 模拟值。
- “模拟已递交”表示在本地原生结构写入并核对 `status/submittedOn/referenceNumber`，没有创建真实账号、点击真实递交入口、支付费用、发送邮件或联系导师。
- 来源使用 `qa.invalid` 标识及注入的虚构 HTML。来源字段测试只证明机制，不证明任何真实学校的规则、名额、资金或资格。没有接触真实个人材料。
- 测试服务器由 `createApp({ dir: 隔离目录 })` 启动，使用系统分配的临时本机端口。未改动正式 `.local/` 或其他运行实例。
- 使用真实 Edge、Playwright、Store 和原始 CLI 副本；每次写入先快照、再干跑校验、按当前版本写入，并等待页面显示对应版本后检查。CLI 采用异步子进程，服务事件循环可正常处理读取和释放文件句柄。
- 已实际查看桌面和手机截图，并操作复制提示词、项目阶段筛选、详情展开、主题切换和手机 Agent 入口。界面测试不限于读取页面标题。

## 第二轮发现并修复的问题

| 编号 | 修复前实际观察 | 修复后实际复核 | 最终结论 |

| R2-02 | 原生记录已获资助、导师已回复，目标页及项目比较仍读取旧摘要，显示尚未核对/尚未联系 | 目标摘要及比较优先读取原生状态，旧字段只供没有原生申请对象的旧记录回退 | 通过 |

Windows 文件替换曾出现占用错误，但复现装置把同步 CLI 与服务器置于同一 Node 进程：父事件循环被阻塞时，已打开的读取句柄不能及时关闭。该装置问题不能当作正式部署的产品缺陷，也没有证据表明数据丢失。改成异步 CLI 后，连续两个全新目录完成所有写入；另有两轮共 300 次存储写入、每次并发 12 次本机读取，写入失败为 0。有限退避增强保留了原子替换、排他锁和失败保留原文件的语义。

较早的详情展开检查还曾把空字符串的 `open` 属性当成关闭状态，产生两项测试误报；已改为读取 DOM 的 `open` 布尔值并重跑。早期中断和误报记录留存，不计入最终 93 项通过结果。

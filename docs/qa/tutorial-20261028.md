## 发现并修复的缺陷

复现：第七课暂存练习版本 1 → 第六课更新及扩展至版本 3 → 刷新 → 返回第七课拒绝坏备份后恢复。初版只在内存保存备份，刷新后却拿当前版本 3 显示“恢复成功”，没有恢复原版本 1。

修复后，受控练习快照随专用教程进度保存。完整重跑实际确认：**版本 1 → 版本 3 → 刷新 → 恢复版本 1 → 再次刷新仍为版本 1**。真实工作区、另一方向和主题没有被恢复动作改变。本轮未发现尚未修复的教程阻断。

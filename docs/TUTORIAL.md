# 新手教程与功能介绍

启动服务后，右上角“帮助”进入 `/#guide`，点“开始新手教程”进入 `/#tutorial`。空档案首页也有“先跟教程练一遍”。静态演示可以使用同一套教程。

教程让你先熟悉工作方式：你通过对话提供信息、确认选择，自己的 Agent 负责配置和更新，网页用于查看计划、搜索、筛选和比较。

## 七课练习

| 课程 | 实际操作 | 学会什么 |
| --- | --- | --- |
| 1. 和 Agent 开始 | 复制分轮引导提示词；复制不可用时可手动复制并确认 | 先检查已有资料，只追问缺口，不要求手工填 JSON |
| 2. 找到目标 | 搜索练习院校，再勾选两个项目比较 | 搜索、筛选和最多三项目比较；查看匹配依据 |
| 3. 回到来源 | 检查变化、选择核对方式，再模拟确认事实 | 网页变化、官方事实和日期周期各自核对 |
| 4. 准备与提交 | 更新材料，逐项目确认推荐信 | 材料就绪不等于已经提交，同一推荐人的不同项目分别跟进 |
| 5. 收到录取之后 | 判断资助是否明确，再模拟接受 | 录取、正式资助、个人决定和入学清单分别维护 |
| 6. 更新与扩展 | 模拟让 Agent 更新待办，增加一份扩展表 | 本地更新后页面同步；简单个性需求使用字段或扩展表 |
| 7. 备份与回看 | 保存练习快照、拒绝损坏备份，再恢复原快照 | 恢复先校验；刷新后仍能取回保存的版本 |

操作后会给出反馈。错误判断不会计作完成；达成每课目标后才标记完成。目录允许自由跳转，跳过会保留“待回看”，不计作完成。离开后再次进入可以续学；硕士和博士分开记录进度。完成后可复制真正的建档提示词，交给自己的 Agent。

## 练习资料放在哪里

练习使用“北岸练习大学”等虚构资料，课程页有明确标识。项目、来源、推荐信和资助展示复用正式页面。搜索与比较只作用于练习预览，不改变真实页面的筛选或正式记录。

浏览器只在 `gradatlas.tutorial.v1` 保存进度、练习操作标记和受控快照标记，不保存真实个人档案。练习备份可跨刷新恢复，也可以在当前方向重置。旧进度损坏时先保留原值，主动重置才替换；浏览器禁止存储时仍能练习，但关闭页面后无法续学。

真实资料仍由 Agent 写在 `.local/`。迁移或恢复真实备份请读 [数据与恢复说明](DATA.md)，教程中的恢复按钮只处理练习。

## 功能入口

| 页面 | 用途 |
| --- | --- |
| 申请总览 | 每日行动、日期与阶段进度 |
| 申请档案 | Agent 整理的背景、目标、约束和硕博专属资料 |
| 目标项目 | 学校、项目或导师搜索，阶段筛选，并排比较，条件与来源 |
| 申请跟踪 | 招生模式、网申、逐项目推荐信、联系与面试 |
| 申请时间线 | 各项官方日期与个人安排，保留时刻、时区、周期和未知项 |
| 材料与任务 | 材料归属、准备状态、待办和计划日期 |
| 来源与更新 | 来源链接、事实核验日、网页变化与读取失败 |
| 录取与入学 | 条件、原币种资助、个人选择及签证注册等事项 |
| 我的扩展 | 自定义字段与表格，以及可信本地源码扩展 |
| 与 Agent 协作 | 引导、更新、版本校验、备份和迁移说明 |

功能介绍里每项都有页面入口和可复制的 Agent 说法。复制仅把文字放到剪贴板；交给你自己的 Agent 后才开始处理。官网定时检查需要另行配置，且只在本地服务运行期间生效。

教程和默认演示用于熟悉操作。真实招生规则另外用[四校官网研究基线](research/README.md)测试，不把练习院校当成实际申请依据。

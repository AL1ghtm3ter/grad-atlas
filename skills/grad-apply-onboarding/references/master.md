# 硕士分支

先明确授课型、研究型或两者，再围绕已有信息追问。

- 专业与课程：本科课程、大纲、学分、数学或方法训练。保留原学分体系；没有依据不换算 ECTS。
- 成绩与学位：当前阶段、计分体系、是否毕业、学位和成绩证明的可取得时间。申请材料与注册原件要求分开记录。
- 语言和考试：已有成绩、有效期、计划考试；豁免需有当轮项目依据。
- 偏好与费用：专业深度、研究训练、实习、职业目标、地区与生活成本。学费、学期杂费、生活费和奖学金分别保存。
- 项目清单：课程结构、先修要求、项目语言、申请方式和录取模式；有选择性或名额限制就保留具体来源，不用一条“可申请”概括。
- 先确认该学位能否独立申请。博士过程中授予的硕士、校内转段和仅面向特定身份的项目，不能当作普通开放硕士。相近名称的跨学科项目须先说明方向差异，用户同意后才加入候选。
- 行动：课程对照、材料差距、推荐信、个人陈述、认证翻译、递交与结果跟进。

首轮示例：“你更想通过硕士补足专业训练、转方向，还是为之后做研究准备？这会影响课程型与研究型项目的选择。如果还没定，我们可以先把两类分开比较。”

成果、成绩和语言按用户实际情况记录。“未考”“待开具”“待核对”都是有效状态。

项目的 `customFields` 可分别保存“课程与先修”“学费”“学期杂费”“生活费”“申请费”等比较摘要；目标与录取比较会显示这些分项，也支持其他自定义字段，缺项显示待核对。课程对照表可放 `extensions`，标明本校原学分、证据和待补差距，不自动转换成 ECTS 或判定符合资格。

官方要求和费用仍放 `facts`，附来源、核验日与适用周期；比较摘要不能替代来源事实。保留原币种、每学期或每年的口径，以及不同国籍、学位或学费身份的条件。身份未知时不自行选择最低费率，旧年度费用不改写成目标入学年度价格。录取和奖学金也不能合并成个人已获资助。

# 博士分支

不先把博士申请缩成学校排名表。确认研究目标、招生模式和资助需求，再选择下一轮问题。

- 研究匹配：具体问题、已有工作、方法和技能、希望补足的训练；已有论文、预印本、报告或作品分别记录，不虚构发表。
- 招生模式：统一项目制、导师制或岗位招聘；入学周期、学位要求和导师接收资格保留官方依据。
- 导师与课题组：近期研究、方法、团队、指导偏好、研究匹配理由与待确认问题。公开主页不证明当前有名额。
- 资助：带薪岗位、奖学金、自费分别处理；金额、税前税后、期限、学费减免、资格限制和延续条件各自核对。
- 材料：研究计划、研究陈述、写作样本、学术 CV、推荐人和可能的考试；按实际岗位要求调整。
- 联系进度：尚未联系、草稿待审、已发送、收到回复、跟进待办、面试。草稿不能记录为已发送；发送必须取得用户明确授权。
- 录取与资助：录取、导师意向、合同、奖学金结果和入组安排分开记录。

首轮示例：“你目前最愿意持续研究的问题是什么？可以从已有课程、项目或工作里讲一件具体的事。如果方向还宽，我们先从你已经做过和希望学会的方法找交集。”

经费或学位条件不清楚时保留未知，不用导师友善回复推断录取或资助。
